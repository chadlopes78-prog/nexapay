I will build the **CheckoutPro Mozambique** SaaS platform with a premium design and local payment integration.

### Phase 1: Authentication & Layout
- Implement Login and Signup pages using Lovable Cloud Auth.
- Create a responsive main layout with a sidebar (Stripe/Kiwify style).
- Setup User Profiles.

### Phase 2: Dashboard & Metrics
- Build the Dashboard with KPI cards (Revenue, Sales, Conversion Rate).
- Integrate Recharts for daily/monthly sales and payment method distribution.

### Phase 3: Product Management
- Build a Product CRUD (Create, Read, Update, Delete).
- Automatic generation of checkout links and QR codes.

### Phase 4: Visual Checkout Editor
- Implement a drag-and-drop style editor for checkout pages.
- Allow customization of logos, colors, testimonials, and video embeds.

### Phase 5: Payment & Checkout Experience
- Create the public Checkout Page template.
- Mock M-Pesa/e-Mola payment flows (webhook-ready).
- Integrate Facebook Pixel tracking.

### Phase 6: Management & Analytics
- Build Customer Management table with export functionality.
- Implement Abandoned Cart recovery tracking.
- Create an Admin Panel for platform oversight.

### Technical Details
- **Framework:** TanStack Start (React + TypeScript).
- **Styling:** TailwindCSS + Shadcn/UI for a premium look.
- **Icons:** Lucide React.
- **Charts:** Recharts.
- **Database:** PostgreSQL (via Lovable Cloud) with RLS for security.
